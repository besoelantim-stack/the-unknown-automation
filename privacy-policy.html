Privacy Policy

The Unknown Automation

Last updated: September 2026

This application ("The Unknown Automation") is a personal content automation tool used solely by its owner/developer to publish content to their own social media accounts (including TikTok).

Information We Collect

This app does not collect, store, or share any personal information from other users. The app only accesses the developer's own TikTok account, using authorized API access, to publish content directly to that same account.

How We Use Information

Access tokens obtained through TikTok's API are used exclusively to post content (videos/images) to the developer's own authorized TikTok account. No data is sold, shared, or used for any purpose other than direct content publishing.

Data Storage

Any credentials or tokens are stored securely and are not shared with third parties.

Contact

For any questions regarding this policy, please contact the developer via the email associated with this application.
